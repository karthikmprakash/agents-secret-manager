# Agent logos

One SVG tile per supported harness, generated from the same mark set the local
UI uses (`AGENT_LOGOS` in `internal/uiserver/ui/index.html`). Marks originate
from [Simple Icons](https://simpleicons.org) and the Hermes project; each tile
keeps the brand color and a white glyph so it stays legible in both themes.

Claude Desktop shares the Claude mark, so it is not duplicated in the landing
strip. The README harness table still lists both.

These are shown only to identify the harness being configured. Product names
and logos are trademarks of their respective owners.
