Built for the way agents actually work.

Values stay in the vault. Agents get two tools and a redacted result.

There is no secret_get

Agents list names and run commands. They cannot pull a value into model context.

$ secret_list
  names · groups · transport · status

$ secret_run
  exit code + captured output
  exact sensitive values → [redacted:NAME]

One vault, every project

Global secrets plus reference-only project manifests. Repositories never hold values.

# .agentsecrets.toml
[secrets.GITHUB_TOKEN]
ref = "vault://global/GITHUB_TOKEN"

Paste anything

Drop .env, JSON, YAML, setup commands, curl headers or a Cloudflare R2 export. Parsed locally, reviewed by you.

Local by default

No account, cloud sync, telemetry or model calls. The vault is age-encrypted and the identity lives in the macOS Keychain. Recovery is a passphrase-encrypted file you own.

age X25519Keychain identityhash-chained auditno network

One path in, one path out.

Agents call MCP. Selected values are injected into a child process. Only the exit code and redacted output return.

Honest boundaries

Useful, not magic.

sm reduces accidental exposure. It does not sandbox code that already runs as you.

Read the threat model

  • Children receive plaintext

    Arbitrary code can encode or exfiltrate credentials. This is not an egress firewall.

  • Redaction is exact-value masking

    Encoded values, raw TTY output and alternate channels are outside the guarantee.

  • Selection is cooperative

    --only and service choose values for well-behaved callers. They are not authorization.

Install sm in a minute.

Download the release binary for your Mac, or build from source. No installer, no account, no background service.

Install sm Release assets

  1. Get the binary

    Apple Silicon or Intel 
    # Apple Silicon, latest release
gh release download \
  -R karthikmprakash/agents-secret-manager \
  -p sm-darwin-arm64

  2. Install and verify

    SHA-256 included 
    shasum -a 256 -c sm-darwin-arm64.sha256
chmod +x sm-darwin-arm64
mkdir -p ~/.local/bin
mv sm-darwin-arm64 ~/.local/bin/sm

  3. Set up once

    Vault, secrets, agents 
    sm onboard
